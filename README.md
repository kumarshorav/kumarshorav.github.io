# SB Aesthetics Digital Audit Library

Static landing page and three existing HTML audit reports, grouped by Website, Instagram and YouTube. No installation or build is required.

## Publish on GitHub Pages

1. Create or open your GitHub repository.
2. Upload the contents of this folder to the repository root: `index.html`, `.nojekyll`, and the complete `reports` folder. Preserve the folder structure.
3. Open Settings → Pages. Choose “Deploy from a branch”, your branch (usually `main`), and `/ (root)`. Save.
4. Open the published link shown by GitHub Pages after deployment completes and share it with the team.

Do not upload only index.html: all three report files are required for its links to work. If you upload this entire folder as a subfolder, the landing page will be under `/github-pages/` instead of at your repository's homepage.

## Contents

- `index.html`: responsive audit landing page with reviewed websites, Instagram profiles, YouTube channels, scope descriptions and report links.
- `reports/website-audit.html`: website review, snapshot 8 October 2026.
- `reports/instagram-audit.html`: Instagram master register, snapshot 8 October 2026.
- `reports/youtube-audit.html`: YouTube evidence register, snapshot 9 October 2026.
- `.nojekyll`: serves the files as a plain static site.

The reports are copied from existing audit artifacts. The landing page does not perform a new audit. Report interfaces contain embedded data; external platform and source links require internet access. Reviewer notes stored in a browser are not shared across team members; use the report's export features to share review decisions.

The supplied ChatGPT links could not be retrieved during preparation. They are preserved as numbered original references without assigning an unverified platform to each link. Platform descriptions and metrics come from the corresponding local report files.
